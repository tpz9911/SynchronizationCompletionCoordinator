## SynchronizationCompletionCoordinator‌

### 【简介 Intro】

**SynchronizationCompletionCoordinator‌** 用于协调团队中执行任务速度不同的各个单位同时完成任务。

软件可设置单位和其执行任务的时间，团队开始时间或结束时间，提示和警告时机，以及可视化的状态提醒。软件支持置顶、半透明和锁定尺寸。

右击空白区域弹出菜单以最大化、最小化或退出。

It used to coordinate units operating at different speeds within a taskforce to complete tasks simultaneously.

The software allows you to configure units and their task durations, taskforce start or end times, reminder and warning timings, as well as visual status alerts. It supports "Always on Top", transparency, and window size locking.

Right-click on any empty area to bring up the context menu to maximize, minimize, or exit.

### 【运行环境 Runtime】

.NET 8+

如果你的 Windows 没有安装过 .NET 8+ 运行环境，程序在第一次运行时将由 Windows 系统跳转到微软网站，引导你下载 **.NET 桌面运行时**。

如果系统没有自动跳转，你也可以手动访问微软 .NET 网站（ https://dotnet.microsoft.com/zh-cn/download/dotnet ），自行下载 **.NET 桌面运行时** 并安装。

If the .NET 8 (or later) runtime is not installed on your Windows system, Windows will prompt and redirect you to the Microsoft website on the first launch to download the **.NET Desktop Runtime**.

If you are not redirected automatically, you can manually visit the Microsoft .NET Download Page to download and install the **.NET Desktop Runtime**.
